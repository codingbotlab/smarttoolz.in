# Reddott Films

This folder is a separate workspace for Reddott-films video projects.

## Purpose

Store the blog/video material and production assets for the videos created so far, separately from the main SmartToolz website code.

## Structure

- `videos/` — finished and source video files
- `blogs/` — blog material associated with the videos
- `images/` — images and visual assets
- `thumbnails/` — video thumbnails
- `audio/` — narration and audio assets
- `captions/` — subtitles/captions
- `metadata/` — titles, descriptions, tags and other publishing metadata

New projects should use their own subfolder so previous generations remain intact.
