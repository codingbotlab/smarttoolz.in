# SmartToolz Video Renderer

Automatic tool tutorial video pipeline using Remotion.

- First tutorial target: `image-background-remover`
- Real SmartToolz page interaction recorded in Chromium
- Tutorial script generated automatically
- Male neural narration generated automatically
- Remotion synchronizes narration and screen recording
- Final MP4 is committed to the repository
- Tool-specific tutorial video is embedded at the bottom of the tool page

## Rendering

GitHub Actions runs the Remotion renderer. No system FFmpeg dependency is required.
